# `planning_commission_project/`

The San Francisco Planning Commission minutes line: 1998–2026 meeting minutes turned into an
**item-level** dataset of discretionary land-use decisions — 16,199 items across 8,958 cases
(the reconciled universe: two-digit years expanded, `case_universe` in
`acquire_external_data.py`; counting the case numbers as printed gives 8,987), in 29
structured fields. The code is in `code/commission_minutes_processing/`; the corpus
itself lives on Dropbox (`MFHR_DATA_ROOT`), never in git.

**One folder per memo.** Each holds `<name>.tex`, its compiled `.pdf`, and its own `figures/`
and `tables/`, so a memo and everything it depends on move together. Every figure and table is
written by a script — nothing in these memos is hand-placed — and each memo's last section
names the script that regenerates it.

## `notes/`

The spec and reference documents the pipeline code links to by path. These are references, not
memos: they are edited when the thing they describe changes.

- `labeling_rules.md` — the SF coding manual a labeller works from; the spec hand labels are graded against.
- `data_infrastructure.md` — the canonical schema and the scrape → parse → label → extract flow, with worked examples.
- `minutes_data_availability.md` — what the raw files actually contain, era by era.
- `processing_review.md` — the 2026-06-05 code review plus the hand-label audit that motivated the current build.
- `schema_enrichment_recommendation.md` — adopt / defer / reject verdicts on candidate fields.
- `hand_label_review_guide.md` — the labelling-app workflow for reviewing labels before they become ground truth.
- `help_string_audit.md` — the field help strings, which *are* the extraction prompt (`build_prompt()` generates it from them).

## Compiling a memo

TeX is installed but not on the `PATH` in non-interactive shells. From inside a memo folder:

```bash
export PATH="/Library/TeX/texbin:$PATH"
pdflatex -interaction=nonstopmode <name>.tex && pdflatex -interaction=nonstopmode <name>.tex
grep -c Undefined <name>.log                        # must be 0
grep -c 'Overfull .hbox.*in alignment' <name>.log   # must be 0 — a table past the margin
```

Track only the `.tex`, its `.pdf` and its `.bib`. Everything else a TeX run emits is
git-ignored.
